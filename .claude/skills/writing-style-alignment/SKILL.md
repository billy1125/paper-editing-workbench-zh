# 寫作風格對齊（Writing Style Alignment）

目的：讓章節檔的文字對齊使用者的寫作風格。檢查依據只有 `writing-style/personal-writing-style.md`，`editing-assistant` 與主對話都照本檔的做法執行。

## 依據

- 唯一依據是 `writing-style/personal-writing-style.md`（以下簡稱「風格檔」）。
- 作用中論文的 `working-papers/<title>/style-guide.md` 有內容時，衝突處從它（CLAUDE.md §0）；空白時略過。
- 引用風格檔時寫出它的大節與小節，例如「論述風格與寫作方法 2.2」「個人筆法 8.1 第 3 點」「格式規範：數字用法」。

## 規則分兩類

風格檔的內容性質不同，檢查時分開處理：

| 類別 | 出處（風格檔） | 檢查方式 |
|---|---|---|
| 要遵守的規則 | 「通用原則」「隨期刊而異」「格式規範」；「論述風格與寫作方法」的八（寫作時的檢查規則）、九（需避免的寫法）；「個人筆法」8.1（編修方向） | 不符合就列出 |
| 作者的既有習慣 | 「論述風格與寫作方法」一到七、十；「個人筆法」1–7 | 不當成錯誤。用來確認改寫後仍保留作者的語感，例如句首「本研究」、以「綜合上述」收束。標 ⚠️ 的習慣依「個人筆法」8.1 處理 |

「個人筆法」8.1 末段列出的項目（半形括號、中英文與數字不加空格、「台」字寫法）維持稿件既有慣例，不列為不符合。

## 做法

1. 讀風格檔，再讀目標範圍在章節檔中的**當下文字**（不用 `revisions/` 的舊快照）。
2. 依該篇 `Basic Information.md` 的 `chapters`，找出目標章節適用的論述架構（「論述風格與寫作方法」二）：

   | 章節 | 適用小節 |
   |---|---|
   | 摘要 | 2.1 |
   | 緒論 | 2.2 |
   | 文獻探討 | 2.3 |
   | 研究模型、研究架構、假說 | 2.4 |
   | 研究方法 | 2.5 |
   | 資料分析、結果、討論、結論 | 2.6 |

   章名對不上上表時，只套用全篇通用的規則，並在回報中註明。
3. 逐條比對「要遵守的規則」，列出不符合處：位置（檔名與行號）、原文片段（30 字內）、依據的節號。
4. 比對「作者的既有習慣」：對照改寫前的文字（`revisions/` 對應紀錄的原文，或使用者提供的原文），列出改寫後消失的作者慣用寫法。沒有改寫前的文字時略過這一步，並在回報中註明。
5. 論述架構類的落差（段落順序、缺少某個推導步驟）碰到 CLAUDE.md §1 的界線，只列「⚠️ 觀察」，不建議改寫。

## 使用者呼叫

- 範圍可以是一段、一節或整章；沒有指定時先問一句。
- 模式由使用者指定，例如 `/writing-style-alignment 建議`、`/writing-style-alignment 直接改`，或用說的。沒有指定時用「建議」。

| 模式 | 做什麼 |
|---|---|
| 建議 | 只列出不符合處，不改稿。依規則分組，每項寫位置、原文片段、依據節號與建議改法，不限項數。使用者要改時，可再指定「直接改」，或交給 `passage-revision` 逐段給版本 |
| 直接改 | 依「做法」找出的不符合處直接修改章節檔，流程見下方 |

「直接改」的流程：

1. 修改前先重讀章節檔的當下文字，確認 old_string 對得上（CLAUDE.md §5 step 2）。
2. 只改「要遵守的規則」的不符合處，保留作者的既有習慣。論述架構類的落差仍只列「⚠️ 觀察」，不改。
3. 每段修改都在該篇 `revisions/` 留底（格式依 `working-papers/_TEMPLATE/revisions/_format.md`，備註寫「writing-style-alignment 直接改」與依據節號），並更新該篇 `progress.md`（CLAUDE.md §5 step 5）。
4. 改完回報每處改了什麼、依據哪一節，以及留底路徑。
5. 「直接改」每段只產出一個版本，是 CLAUDE.md §5 step 3「一律多版本」的例外，只在使用者明確指定時使用。

## editing-assistant 使用時

- `editing-assistant` 在 frontmatter 以 `skills` 預先載入本 skill，在時間點 B、C、D 照「做法」檢查。
- 一律只回報，不改稿，也不建議切換到「直接改」。
- 結果放在回報的【風格對齊】區，最多 5 項；超過時最後一項寫「另有 N 項」。

| 時間點 | 檢查 |
|---|---|
| B 改段前 | 列出這一段適用的規則，以及目前文字不符合的地方，讓改寫時一併處理 |
| C 採用後 | 檢查採用的版本：有沒有不符合規則的地方，有沒有丟掉作者的慣用寫法 |
| D 一章收尾 | 對整章檢查，依規則統計不符合數 |

## 界線

- 只處理中文語言層面，不修改研究邏輯、論點順序、主張、數據與引用。
- 領域術語、譯名、縮寫維持作者寫法，除非風格檔的規則明確要求統一。
- 疑似邏輯或事實問題 → 以「⚠️ 觀察」列出，不自行更動。

## 輸出格式（建議模式）

```
【檢查範圍】<章節檔與段落>｜適用論述架構：<小節或「未對應」>

— 要遵守的規則
1. <檔名> 第 N 行：「<原文片段>」→ <建議改法>（依據：<節號>）
…

— 消失的作者慣用寫法
1. <位置>：原文的「<寫法>」改寫後不見了（依據：個人筆法 <節號>）
（沒有改寫前的文字時寫「略過：沒有改寫前的文字」）

⚠️ 觀察（如有）：…
```
