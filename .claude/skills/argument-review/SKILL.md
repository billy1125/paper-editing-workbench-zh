# 學術論證與修訂

## 工作原則

- 僅使用使用者提供的草稿與已確認的研究資訊，不補造作者、年份、文章題目、DOI、研究結果、樣本資訊或模型路徑。
- 先檢查、再修訂。保留作者的研究問題與原有研究設定；任何實質調整都要明確揭露。
- 本 skill 不查證引用、不新增或移除引用、不改動 `[Verified]`、`[No Reference]`、`[Need Reference]` 等標籤。引用相關事項一律交給 `citation-source-verification`。
- 研究上的假設、推測、理論延伸、統計關聯與因果主張需清楚區分。
- 遵守使用者要求的論文章節定位、文字風格與引用格式；未指定時使用台灣繁體中文、學術白話文與作者—年份引用。

## 執行流程

### 1. 確認研究設定

從原文擷取：研究背景、研究目的、理論架構、主要構面、構面角色（前因／中介／調節／結果）、資料來源、研究設計、樣本數、分析方法、研究問題與宣稱的貢獻。不得由文字空缺自行推出未揭露路徑、資料結果或量表設計。若有矛盾，先列出矛盾；修訂時依有較多直接陳述支持的設定處理並標明未決部分。

### 2. 檢查論證邏輯

逐段檢查：

1. 背景 → 實務現象 → 理論機制 → 文獻已知 → 未解問題 → 研究目標 → 研究問題 → 方法 → 預期貢獻，是否存在無證據跳躍。
2. 研究缺口是否真正尚未被文獻回答；不能把「較少研究」「沒人做過」「首次」當成未查證事實。
3. 概念是否正確區分，例如採用意圖／持續使用意圖、資料揭露意圖／行為、隱私顧慮／感知風險、信任／信任傾向、前因／調節、中介／因果機制。
4. 理論上的構面先後與研究設計能支持的推論是否一致；橫斷面觀察性資料不得直接證明因果或時間順序。
5. 研究問題、假說、實際估計路徑、方法及理論貢獻是否完全對齊。
6. 形成性與反映性測量是否混淆；形成性權重不等於構面對結果的路徑係數，也不等於個別維度的因果效果。
7. 穩健性檢查是否真正在測試原結論的穩定性；不同理論命題的交互作用模型通常應標作補充分析。

檢查中發現論點缺少文獻支持、或引用與論點的對應可能有問題時，只記錄位置與原因，列入「未解決事項」，建議使用者以 `citation-source-verification` 處理，不自行查證或調整。

### 3. 修訂文字

- 保留既有研究核心與可確認事實。把過度確定的說法降為合適程度，例如「證明」→「發現關聯」，但不能因此掩蓋研究本身有實驗或因果識別的情況。
- 原有引用與標籤照原樣保留，跟著所支持的敘述走；改寫時句子移位，引用一起移，不拆開、不刪除、不新增。
- 區分文獻的結果與本研究的假說／待檢驗推論。
- 緒論聚焦：研究背景、問題重要性、真正研究缺口、研究目的、主要貢獻；過度詳細的路徑與衡量技術可移至研究架構／方法，但未經授權不要擅自刪除必需內容。
- 維持術語一致、避免同義反覆及重複推論，段落以結論先行的中短句呈現。
- 對原文中的樣本數、構面數、研究國家、分析方法、正式研究結果，未有其他證據不可任意更動。

### 4. 交付格式

當要求完整檢查與修改後版本時，依序提供：

1. **核心判斷**：用簡短段落列出最關鍵的邏輯問題。
2. **邏輯檢查表**：問題所在、為何有問題、處理方式，優先顯示會改變研究主張的問題。
3. **完整修訂稿**：可直接作為學術草稿，原有引用與標籤照原樣保留。
4. **未解決事項**：只列實質影響研究設定或模型一致性的問題，以及需交給 `citation-source-verification` 處理的引用事項，不額外提出未被要求的新研究規劃。

使用者只要求局部修訂時，只輸出相關局部內容。使用者要求完整文章則輸出完整修訂稿，不因一般篇幅限制省略。

## 出稿前檢核

- 修訂稿的所有研究問題、理論構面、實際估計路徑及貢獻對齊。
- 原有引用與標籤沒有被新增、刪除或改動。
- 相關不被寫成因果；中介係數不被直接解釋為已識別的因果機制。
- 文獻缺口不與已知近似研究相衝突。
- 不新增使用者未提供的模型路徑或量測假設。
- 形成性權重、路徑係數、交互作用的統計解釋正確。
- 文字使用台灣繁體中文，全形中文標點，中文與英文／數字間空一格。
