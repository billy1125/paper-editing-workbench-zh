# 個人寫作風格（跨論文共用）

> **這是可編輯範本。** 本檔由**使用者自行修改與擴充**，沒有對應的 skill。AI 不會自動改寫本檔；要更新請直接編輯，或明說要調整哪一條。

本檔是跨所有論文共用的**個人寫作風格**，內容包括資管（IS）中文論文的通用預設、論述架構與個人筆法（見 `CLAUDE.md` §0、§3）。

**優先順序：** 先依作用中論文的 `working-papers/<title>/style-guide.md`，再依本檔；衝突時該篇 `style-guide.md` 優先。該篇 `style-guide.md` 是投稿期刊的寫作指引，由使用者設定；空白時略過，直接依本檔。下方「隨期刊而異」的項目（用語用字、人稱、標點、引用格式），該篇 `style-guide.md` 有規定時從它，沒有規定時套用本檔的預設值。

> `passage-revision`、`section-review` 在該篇 `style-guide.md` 不存在或空白時，以本檔為依據。

## 通用原則（各篇多半一致）

- **語域／可讀性**：正式的學術書面語（臺灣繁體中文），好讀優先——不用口語，不堆砌文言腔、冗長句、非必要專有名詞（詳見 CLAUDE.md §6 通用原則）。
- **句式**：以清楚為準，避免歐化句式——濫用「被」字句、「進行／加以／予以＋動詞」的弱動詞結構、「關於／對於」開頭的冗贅句、「的」字連用三次以上、「…性／…化／…度」名詞堆疊。方法描述可省略主詞，論點陳述以「本研究」為主詞。
- **時間與完成的表述**：中文沒有時態變化，一致性看時間詞與「了／已／曾／將」的用法。引述文獻用「指出／發現／認為」直述；本研究已執行的程序與結果直述即可，不加多餘的「了」；研究限制與未來研究用「可／將」。同一章節內寫法保持一致（細節由 `final-consistency-sweep` 掌握）。
- **術語**：領域專有名詞（如科技信任、構念、調節效果、SEM…）保留作者的寫法並全文一致，非經作者要求不改動。英文術語首次出現採「中文譯名（英文原文，縮寫）」，其後固定用同一個中文譯名或縮寫；沒有通行譯名的術語保留英文原文。

## 隨期刊而異（投稿期刊有規定時從其規定，沒有規定時用此預設）

- **用語地區**：預設**臺灣用語**（資訊、軟體、網路、品質、使用者），不用中國用語（信息、軟件、網絡、質量、用戶），全文統一。
- **用字變體**：「臺／台」「佔／占」「裡／裏」等異體字全文擇一；預設沿用稿件多數寫法並統一。
- **敘述人稱**：預設以研究為主詞的**客觀第三人稱**（本研究），節制使用「我們」「筆者」；「本研究」「本文」不混用，若期刊慣用其他自稱則改從期刊。
- **標點**：預設使用**全形標點**；並列詞語用頓號、並列分句用逗號或分號；引號用「」、內層用『』；書名用《》、篇名用〈〉；破折號（——）與刪節號（……）各佔兩格，全文一致。
- **引用格式**：預設 **APA 7th**，依目標期刊實際要求調整。引用的文獻以英文為主，文內保留作者原文姓氏，如「Davis (1989)」「(Venkatesh et al., 2003)」；括號與分隔標點的全半形全文擇一。

## 格式規範（可依你的習慣調整）

> 這一段強化「格式一致性」，涵蓋標點、數字、術語、排版。定稿前由 `final-consistency-sweep` 逐項核對。以下為預設值，**請自行改成你或目標期刊的規範**。

- **全形與半形**：中文語句的標點用全形；英文片語、數字、統計式內部用半形。括號夾中文時用全形（），純英文或數字時是否用半形，依目標期刊，全文擇一。
- **中英文與數字間距**：中文與英文、數字之間是否加半形空格，全文擇一；預設沿用稿件多數寫法並統一。
- **數字用法**：統計值、量測值、樣本數、百分比、年份、編號用阿拉伯數字；慣用語與概數用國字（一方面、兩者、三大構面）。數字／年份區間用 en-dash 或「至」（`20–29`、`2019–2021`），全文擇一。
- **數字與統計**：樣本數小寫斜體 `n = 278`；百分比數字緊接無空格 `42.4%`；統計值省略前導零 `p < .05`、`β = .32`（β／t／p 以斜體、半形），但一般文字描述保留前導零 `0.3%`。
- **圖表稱呼**：`圖 1`、`表 2`（不混用「圖一」「Figure 1」）；文中指稱寫「如表 2 所示」。
- **強調與斜體**：中文不用斜體強調，粗體節制使用；斜體只用在統計符號與英文書刊名。中文書刊名的標示方式（書名號或粗體）依目標期刊。
- **術語與縮寫一致**：同一概念全文固定一個中文譯名；英文縮寫與大小寫固定單一寫法（例：`FinTech` 不混用 `fintech`）。首次出現給中文譯名＋英文全稱＋縮寫，其後用譯名或縮寫。
- **英文術語大小寫**：中文譯名後括號內的英文原文視為專有名詞，首字大寫，介係詞小寫，如「隱私計算理論 (Privacy Calculus)」。
- **清單樣式**：預設將短清單整合進散文（見 CLAUDE.md §6）；僅步驟性／逐條對應才保留條列。

## 論述風格與寫作方法

以下是作者學術論文的論述方式與寫作方法。這些是可觀察到的傾向，不代表每段都遵循同一模板。

### 一、整體文風定位

1. **正式、客觀、偏向解釋性論述。**以「本研究」「過去研究」「相關學者」「研究結果」為主詞，少使用第一人稱情緒評價；主張一般附上理論、引用或研究情境說明。
2. **由背景逐步收斂到研究問題。**先交代技術、社會或實務情境，再說明既有研究可提供的知識，最後指出尚未充分處理的問題與本研究目的。
3. **重視概念定義與文獻承接。**先介紹概念源流與學者觀點，再統整適用於本研究的工作定義，接著說明如何被衡量或用來推導關係。
4. **採累積式段落。**一個段落通常容納數個相關判斷，以「由於／然而／因此／此外／故」建立前後關係，並非單句式短段落。
5. **研究情境導向。**理論介紹後，通常回到特定使用者、系統、服務或教學場域，說明理論為何可適用於該情境。
6. **實證程序具體。**研究方法傾向依時間或分析程序呈現，交代對象、工具、資料蒐集、分析方法與評估指標。
7. **結尾回扣研究目的。**論述結尾通常交代可補足何種研究問題，以及研究成果對學術研究或實務應用的用途。

### 二、各章節的典型論述架構

#### 2.1 摘要

常見順序為：**研究背景／問題 → 研究目的 → 研究方法 → 主要發現 → 研究用途或貢獻**。量表研究的摘要直接點出因素分析及構面／題項結果；研究計畫通常沒有已完成的實證結果，不可照搬結果式摘要。

撰寫規則：每個句子負責一項資訊。方法須指明實際採用的設計；結果須使用實際數據，未取得結果時不得預寫為已證實。

#### 2.2 緒論與研究背景

常見的五段式推進：

1. **大環境：**技術進展、政策或社會現況，說明主題重要性。
2. **研究對象：**介紹研究系統、使用者或場景的核心特徵。
3. **問題與矛盾：**在既有優勢之外，指出限制、風險或尚未被解釋的現象。
4. **文獻缺口：**說明既有研究聚焦何處，而本研究所需的情境、構念或機制尚缺乏充分探討。
5. **研究定位：**提出研究目的、研究設計概述及預期／實際貢獻。

**特徵：**不直接以「研究很重要」取代論據，而是從具體應用與理論限制逐步形成問題意識。可保留收斂式論證，但應避免在背景與動機間逐段重述相同主張。

#### 2.3 文獻探討

典型結構為：**概念起源或定義 → 代表性研究觀點 → 構面／分類 → 各研究比較 → 本研究的界定與應用**。

- 介紹概念時，常使用「某學者指出／認為」「依據某研究」「過去研究將……區分為……」。
- 對一個概念提供多種定義後，使用「綜合上述學者的觀點，本研究將……定義為……」形成工作定義。
- 重要分類使用分項敘述，逐一說明其概念與應用情境。
- 結尾連回研究工具、模型構念或研究假說，而非停留於文獻羅列。

**品質界線：**文獻的年份、作者、主張與原文意義應逐一核對。可模仿整合方式，不能直接沿用尚未查證的引文或將多篇研究的結論過度概括。

#### 2.4 研究架構與假說發展

典型推導順序為：

1. 指明構念的理論來源與定義。
2. 描述構念在研究情境中的具體意義。
3. 援引先前研究支持某種機制或關聯。
4. 說明機制如何連結自變項與依變項，以及可能的方向。
5. 以「根據以上推論，本研究提出下列假說」引出明確可檢驗的假說。

假說文字宜使用「X 正向影響 Y」「X 負向影響 Y」，且與研究模型中的變數名稱一致。**如果文獻只支持相關而不是因果，須另說明提出方向性假說的理論理由；不以寫作語氣代替證據。**

#### 2.5 研究方法

偏好依**研究設計 → 研究對象 → 研究工具／操弄 → 前測與專家檢核 → 資料蒐集程序 → 資料分析**的順序說明。

- 量表建構研究以探索性因素分析、驗證性因素分析等流程呈現工具發展與驗證。
- 教材開發研究交代教材工具、開發平台、雛形迭代、使用程序、專家檢核與試用。
- 研究計畫交代預計樣本、實驗組別、操弄條件、問卷與統計分析，並常另列時程與可能困難。
- 分析方法名稱、評估指標與使用目的通常一併呈現，而非僅羅列方法名稱。

**時態規則：**完成研究使用「本研究採用／資料顯示」；計畫階段使用「預計／將／擬」。兩者不可混寫成研究已完成。

#### 2.6 結果、討論與結論

已完成的實證論文將資料結果與研究目的連結，說明構面結構、接受度或研究工具用途。可延伸為：**結果陳述 → 對應研究問題 → 與既有研究對照 → 理論／實務意涵 → 限制與未來研究**。

研究計畫的「預期成果」則以**擬完成的工作、方法貢獻、學術用途及實務應用**為主，不宜使用「研究證實」「結果顯示」等完成式表述。

### 三、句法、語氣與連接方式

| 功能 | 常見的表達傾向 | 建議保留的寫法 |
| --- | --- | --- |
| 說明背景 | 由於……；近年來，隨著…… | 「近年來，隨著 X 的發展，Y 已逐漸應用於 Z。」 |
| 文獻引入 | 依據……；過去研究指出…… | 「依據 A（年份）的研究，X 可區分為……。」 |
| 補充機制 | 此外……；並且……；再者…… | 「此外，X 亦可能透過 M 影響 Y。」 |
| 對比與缺口 | 然而……；雖然……但是…… | 「然而，既有研究主要聚焦於 X，對 Y 的探討仍有限。」 |
| 推論 | 因此……；故……；進而…… | 「因此，當 X 改變時，可能透過 M 影響 Y。」 |
| 定義 | 本研究定義……為…… | 「本研究將 X 定義為……，並以……衡量。」 |
| 假說收束 | 根據以上推論，本研究提出…… | 「綜合上述理論與實證研究，本研究提出以下假說。」 |
| 段落收尾 | 期望提供……參考；可作為…… | 「研究結果可作為後續 X 研究與 Y 設計之參考。」 |

**語氣強度：**主要使用「可能」「可」「有助於」「傾向」「預期」處理尚未驗證的推論；已經有資料支持時，才使用「研究結果顯示」。

### 四、用詞與學術術語習慣

- 優先使用「本研究」「研究對象」「研究架構」「研究構面」「研究假說」「研究工具」「資料蒐集」「資料分析」「信度與效度」「實證結果」「感知風險」「使用意願」等研究領域既有詞彙。
- 首次引入專業概念，常採「中文名稱（English Term, ABBR）」；後文使用中文簡稱或縮寫。英文名稱與縮寫必須確認正確，不照抄文獻中的拼寫或縮寫錯誤。
- 常將「認知／態度／行為」、「理論／方法／實務」、「系統／使用者」分層分析，避免同一段交錯處理不同分析層次。
- 可使用「探討」「檢驗」「衡量」「驗證」「比較」「歸納」「整合」「建構」「分析」等動詞，明確區分研究工作的性質。
- **不把篇幅長、術語密集或因果連接詞多本身視為學術嚴謹。**重點是主張清楚、文獻可追溯、研究步驟可重現。

### 五、引文與證據配置

1. 概念定義、理論來源、技術特性與先前實證結果，通常在相應句末標註作者與年份。
2. 單一段落會整合數篇文獻，以支持同一觀點或比較不同研究；引用不是越多越好。
3. 學者觀點應分開呈現，再以「綜合」或「因此」形成作者自己的研究定義與推論。
4. 研究缺口需界定**範圍**，例如特定情境、研究對象、變數關係、操作化方式；不能僅以「研究不多」作為充分證據。
5. 作者連接符號、英文括號與縮寫用法，應以目標期刊引用規範（例如 APA）統一，不沿用不一致的格式。
6. 不補造作者、年份、研究結果、樣本數、統計值或研究缺口。

### 六、期刊論文與研究計畫的差異

| 面向 | 期刊論文傾向 | 研究計畫傾向 |
| --- | --- | --- |
| 核心任務 | 報告已完成研究並解釋證據 | 說明為何值得研究、如何執行及預期成果 |
| 時態 | 已採用、顯示、發現 | 預計、將、期望、擬 |
| 緒論終點 | 明確研究問題與已實施研究 | 研究目的、執行方向與預期影響 |
| 方法 | 報告實際操作與分析 | 陳述研究設計、流程、預期樣本及風險 |
| 貢獻 | 依實際結果提出 | 依研究設計提出合理預期 |
| 特有章節 | 結果、討論、研究限制 | 執行進度、預期困難、預期工作與成果 |

### 七、可以直接套用的寫作框架

以下為示意句型，不是具實證效力的研究陳述。

#### 7.1 研究背景段

> 近年來，隨著〔技術或環境變化〕，〔研究對象〕已逐漸運用於〔應用情境〕。相關研究指出，〔已有理論支持的功能或影響〕（〔來源〕）。然而，〔具體限制或問題〕仍可能影響〔研究對象或結果變項〕。因此，探討〔核心研究議題〕，有助於進一步理解〔待解釋的機制或現象〕。

#### 7.2 文獻整合段

> 〔構念〕是指〔附來源的定義〕。過去研究分別從〔面向 A〕與〔面向 B〕加以探討（〔來源 A〕；〔來源 B〕）。其中，〔主要差異或共同點〕。綜合上述觀點，本研究將〔構念〕定義為〔與研究情境一致的工作定義〕，作為後續〔衡量或假說〕的基礎。

#### 7.3 假說推導段

> 依據〔理論〕，當〔自變項〕改變時，可能透過〔具體作用機制〕影響〔依變項〕（〔來源〕）。在〔本研究情境〕中，〔解釋此機制為何適用〕。相關實證研究亦指出〔需實際核對的相關發現〕（〔來源〕）。因此，本研究推論〔方向與關係〕，並提出以下假說：
>
> **H1：〔自變項〕正向影響〔依變項〕。**

#### 7.4 研究方法段

> 本研究採用〔研究設計〕，以〔研究對象及納入條件〕為研究對象。研究工具包括〔量表、操弄或教材〕，其內容參考〔文獻或理論〕進行設計。正式蒐集資料前，先透過〔專家檢核或前測〕確認〔適切性或可理解性〕。資料蒐集完成後，將以〔分析方法〕檢驗〔研究問題、衡量品質或假說〕。

#### 7.5 預期貢獻段（研究計畫適用）

> 本研究預期在理論、方法與實務三個層面提供參考。在理論層面，〔擬釐清的機制或範圍〕；在方法層面，〔研究設計或衡量方法的用途〕；在實務層面，〔可合理導出的應用方向〕。上述貢獻仍須依後續研究結果進一步評估。

### 八、寫作時的檢查規則

- [ ] 緒論是否依序說明背景、問題、缺口與研究目的？
- [ ] 概念是否先有文獻定義，再提出本研究的操作性定義？
- [ ] 每個研究假說是否具有明確的理論機制，而非只列引用？
- [ ] 是否區分「先前研究發現」「本研究推論」與「本研究結果」？
- [ ] 是否交代研究設計、樣本、工具、資料蒐集與分析方法？
- [ ] 是否避免重複定義、重複背景及連續多次使用「因此」？
- [ ] 每一個數據、引文、術語縮寫是否可查證？
- [ ] 結論是否只延伸至資料能支持的範圍？
- [ ] 引用與中英文標點是否符合投稿期刊規範？
- [ ] 研究計畫與已完成論文的時態是否一致？

### 九、需避免的寫法

- 長句中反覆使用「由於」「因此」「並且」，造成因果關係不明或資訊重複。
- 研究重要性、貢獻與應用價值以類似句型在多處重述。
- 用「可提升」「有效改善」推導研究效果，但未在該段提供足以支持強度的證據。
- 術語、縮寫、方法名稱、引用格式的處理前後不一致；應以正確學術規範統一。

### 十、可供後續寫作使用的濃縮指令

> 以台灣繁體中文撰寫資訊管理與應用社會科學領域的學術論文。採正式、客觀、文獻導向的論述語氣。每節由概念或背景起始，綜整代表性研究，明確界定研究缺口，然後收斂至本研究的定義、模型、假說或方法。段落內應具有清楚的背景、依據、比較、機制與結論；構念先定義，再解釋適用情境與變數關係。使用「依據」「然而」「此外」「因此」「綜合上述研究」等銜接詞，但避免機械重複。文獻與統計資訊須可查證，不能虛構。區分文獻發現、理論推論、研究設計與實際結果。方法描述須具體且可重現。若為研究計畫，使用預期式時態；若為已完成論文，根據實際結果陳述，不超出資料推論。用詞、英文術語、縮寫、假說編號及引用格式全文一致。

## 個人筆法

以下是作者既有的中文筆法習慣。標 ⚠️ 的是個人習慣與本檔前段預設（通用原則、隨期刊而異、格式規範）不一致之處；編修方向以本節 8.1 為準。

### 1. 語氣與正式度

- 正式的學術書面語，白話為底，帶文言虛詞。「之」常與「的」並用，如「本研究之研究目的」「使用者之感知透明度」。
- 其他常見文言虛詞：於、亦、均、係、故、惟、是以。
- 不用驚嘆語氣；偶用成語式修辭（「如雨後春筍地推出」「浮上檯面」）。
- 偶有較口語的說法，如「這包括」「這是由於」「比如」「在這項研究中」。
- 資訊密度高，一句內常同時交代原因、作法與目的。
- ⚠️ 「之」「進行」的使用密度與前段「不堆砌文言腔、避免弱動詞結構」的預設有出入。

### 2. 人稱與句式

- 自稱以「本研究」為主，也是最常見的句首；不用「筆者」。
- 偶有「我們」「本文」「本計畫」與「本研究」混用，如「我們將邀請…」「幫助我們理解」。
- 指稱他人研究用「學者」「過去研究」「相關研究」「既有研究」「部分研究」，如「學者Kotler…認為」。
- 指稱國家用「我國」，如「我國民眾」；也用「國內民眾」「台灣地區」。
- 「被」字句常見，如「得以被更全面地蒐集」「被消費者所在意」。
- 「進行」＋名詞的結構多，如「進行分析」「進行信效度驗證」「進行修訂量表問項」。⚠️ 與預設不一致。
- 「對於」常見。
- 常用無主句承接前文，如「並可作為…」「試圖根據…」。

### 3. 句構與句長（含偏好開頭句型）

- 句子長，一句常以多個逗號串接，偶有數百字的長句。
- 段落長，常一段講完一個完整論點。
- 偏好的句首：
  - 原因起手：「由於…，因此…」「隨著…」「近年來，…」
  - 研究行動：「本研究以…」「本研究採用…」「本研究旨在探討…」「本研究將…」「本研究預計…」
  - 依據：「依據…」「基於…」「根據…」
  - 對比：「相較於…」「有別於…」
  - 目的：「為確保…」「為了解…」
- 固定句式：
  - 定義：「X可定義為：…」「本研究定義X為「…」」「係指一種「…」」「亦即…」
  - 目的清單：「具體而言，本研究之研究目的如下：」「…分述如下：」
  - 分層說明：「本研究由理論、方法與實務三個層面來說明」「在實務方面，…在學術方面，…」
  - 研究缺口：「…之研究則不多見」「相關實證仍相對有限」「仍有待釐清」「目前仍呈現較少數量」
  - 假說，兩種寫法：「H1：推薦系統的演算法意識正面影響感知效益」；「H1 (感知透明度)：不同…將對…產生顯著差異。」
  - 結果：「結果顯示，…」「分析結果請見表7」「如表3所示」
- 句內列舉用「1)…；2)…；3)…」，項目間用分號。

### 4. 用語與標點慣例（含依章節的時間表述）

- **用語用字**：臺灣用語（資訊、網路、軟體、使用者、消費者、演算法）。「台灣」寫作「台」，沒有用「臺」。「數據」與「資料」並用。
  - 「私隱資訊」是常用寫法，與「隱私」並用，如「個人私隱資訊」。
  - ⚠️ 偶見與臺灣用語預設不一致的寫法，如「質量增長」「用戶數」「信息」「算法」。
- **術語譯名**：首次出現寫「中文譯名(English Term, 縮寫)」，英文各字首大寫，如「行動商務(Mobile Commerce)」「人工智慧(Artificial Intelligence, AI)」。之後用中文譯名或縮寫（AI、XAI、SAT、PLS-SEM）。
- **強調與概念標示**：核心概念、理論與量表名稱用「」框起，如「校準信任」「隱私疲勞」「黑盒子」；偶用粗體標示重點。
- **標點**：
  - 逗號、句號、頓號、冒號、分號在中文句內用全形。
  - 括號幾乎全用半形 `()`，括號前後不留空格。⚠️ 與預設「夾中文用全形括號」不一致。
  - 並列選項用斜線，如「高/低適配」「移動性/無所不在/可及性」。
- **中英文與數字間距**：不加空格，如「以AI演算法為核心」「共29題」「表1」。⚠️ 與使用者全域排版規則（中英文間加空格）不同，稿件內以稿件慣例為準。
- **數字**：統計與題數用阿拉伯數字（「29題項」「69.47%」「300至400名」）；數量詞阿拉伯數字與國字混用（「6個構面」「六構面」「三位」「研究1」「研究一」）。
- **統計寫法**：寫作 `p<0.001`、`p < 0.05`（保留前導零，空格不一致）。
- **引用**：
  - 括號式用半形，多筆以分號分隔，如 `(Lee & See, 2004; Merritt et al., 2015)`。
  - 敘述式作者後直接接括號，寫法不一：`Pavlou et al.(2007)`、`Fornell and Larcker(1981)`、「Zarouali等人(2021)」、「Shin與Park」、「Lee和See」並存。
  - 括號內的作者連接詞 `and` 與 `&` 並用。
  - 中文文獻：`(郭英峰與游景文，2007)`；書目格式為「作者，年份，「題名」，期刊名，卷期，頁碼。」
- **章節編號**：期刊論文用「壹、／一、／(一)」；研究計畫用「1.1／1.1.1」。
- **時間表述**：
  - 背景與文獻：用「已」「近年來」「過去」，如「已成為」「過去研究指出」。
  - 研究計畫的方法：用「將」「預計」，如「本研究將以…檢驗」「預計以…進行」。
  - 已完成研究的方法與結果：直述，不加時間詞，如「本研究採用…」「結果顯示…」。
  - 「了」常見，如「改變了」「顯示了」「增強了」。

### 5. 過渡與段落

- 連接詞集中在少數幾個：
  - 因果：「因此」最常用，常直接接主詞不加逗號，如「因此本研究…」「因此生活型態…」；另有「故」「進而」「使得」「從而」。
  - 遞進：「並且」常見，常放句首，如「並且隨著…」「並且由於…」；另有「進一步」「加上」「同時」「再者」。
  - 轉折：「然而」「但是」「雖然…但是…」「儘管…」「反之」。
  - 換句話說：「亦即」「換言之」。
  - 收束：「綜合而言」「綜合上述」「綜上所述」「基於上述背景」「依據以上的討論」。
- 「此外」「另外」很少用。
- 段落結構：先鋪背景（由於／隨著），再接問題或限制（然而），最後以「因此／故本研究…」收到研究行動或重要性，如「實屬…重要的議題」。
- 文獻小節結尾會寫一段小結，指出缺口後帶出本研究的切入點。
- 貢獻與重要性固定分層寫：理論／方法／實務，或學術／實務。

### 6. 用詞：偏好／避免（附語詞替換）

- **偏好動詞**：
  - 研究行動：探討、檢視、檢驗、建構、發展、提出、驗證、釐清、聚焦於、試圖
  - 引述文獻：指出、認為、提出、主張、強調
  - 結果：顯示、表示
  - 手段：透過、藉由、依據、基於、以…為基礎
  - 效果：提升、促進、強化、深化、補足、協助、有助於
- **偏好名詞搭配**：重要議題、重要變項、研究工具、實證資料、實證參考、作用機制、研究缺口
- **依據的說法**：「依據」「根據」並用。
- **少用或不用**：筆者、此外、另外、總之、所以（多用「因此」）。

### 7. 主張強度

- 整體偏保守到中等。
- 常用的保留說法：「可能」「應可」「有助於」「期望」「試圖」「視為」。
- 結果陳述用「結果顯示」「表示…應具有」，不用「證明」。「證實」只在引述既有研究時出現。
- 研究缺口用緩和說法：「則不多見」「仍相對有限」「仍有待釐清」「較少檢驗」。
- 貢獻陳述較肯定，但仍以「有助於」「可作為…之參考」「提供…實證依據」表達，不用絕對化字眼。
- 研究限制直接陳述，並提醒解讀時「仍須特別謹慎與留意」。

### 8. 使用者手動補充

- （此區塊不由 AI 覆寫）

#### 8.1 編修方向：簡潔清晰，但不失論文的重量

§1–§7 記錄的是既有習慣；編修時以本節為準，與 §1–§7 的習慣衝突時依本節修改。原則是刪掉不帶資訊的字，保留帶資訊的字：術語、引用、數字、研究缺口與保留語氣都要留。

1. **拆長句**：一句只放一個論點。「由於…，因此…，並且…，進而…」連接成的長句，在「因此」「然而」前斷句。
2. **提出跨段重複**：同一句或同一論點在不同段落重複時，以「⚠️ 觀察」提出去重選項，不自行刪除（依 CLAUDE.md §6）。
3. **「進行＋名詞」改回動詞**：「進行分析」改「分析」，「進行信效度驗證」改「驗證信效度」。
4. **減少連接詞**：「因此」「由於」只在確有因果時保留；句首的「並且」可刪則刪。
5. **化解「被」「對於」句**：「被消費者所在意」改「消費者更在意」；「對於行動商務服務產生疑慮」改「對行動商務服務存疑」。
6. **每個主張只留一個保留詞**：「應可考量納入」改「可納入」。保留語氣本身要留，不疊用。
7. **空泛的重要性改成具體理由**：遇到「實屬…重要的議題」這類句子，若原文已有具體的缺口或影響對象，改用該內容表達；原文沒有時以「⚠️ 觀察」提醒，不自行補寫內容。
8. **統一寫法**：自稱固定用「本研究」，不混用「我們」「本文」「本計畫」。「私隱／隱私」、敘述式引用（et al.／等人）每篇各擇一；投稿期刊有規定時從其規定，沒有規定時依稿件多數寫法統一。
9. **「之」的用法**：保留在固定搭配（如「…之影響」「本研究之目的」）；同一句內不混用「之」與「的」。

本節不處理的項目：半形括號、中英文與數字不加空格、「台」字寫法，維持稿件既有慣例；投稿期刊有規定時從其規定。
